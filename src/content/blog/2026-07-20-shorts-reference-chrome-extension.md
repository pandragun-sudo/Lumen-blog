카톡 나에게 보내기에 끝없이 쌓이는 유튜브 링크들을 보며 구역질이 났다. 나중에 다시 열어보면 영상은 지워져 있거나 메타데이터는 완전히 변형되어 있다. 그때 그 시점의 조회수와 맥락은 영원히 날아가는 거다. 게다가 쇼츠는 시크바도 없어서 특정 구간을 반복해서 보려면 멍청하게 화면을 두드려야 했다. 

참다못해 크롬 확장 프로그램을 팠다. 거창하게 서버를 두면 돈이 드니까 브라우저 로컬 스토리지에 데이터를 욱여넣는 로컬 퍼스트 구조로 잡았다. 캐시 날리면 데이터도 다 날아가는 끔찍한 단점이 있지만, 뭐 어떤가. 공짜로 쓰는 건데.

| 한계 | 원인 | 현재 상태 |
|---|---|---|
| 브라우저 캐시 삭제 시 데이터 손실 | 로컬 스토리지의 구조적 특성 | 수동 내보내기로 백업은 가능 |
| 폴더 분류 미지원 | MVP 단계에서 불필요한 기능 확장 억제 | 다음 버전에나 고려 예정 |
| Chrome 웹스토어 미등록 | 스토어 심사 절차 진행 중 | 텔레그램으로 로컬 설치 파일 배포 중 |

패널 하나 열고 클릭 한 번이면 영상 제목, 현재 조회수, 구독자 수까지 모조리 긁힌다. 시크바 제어까지 먹여놨다. 완벽하진 않다. 폴더 분류 기능 같은 건 귀찮아서 아예 안 만들었다. 어차피 지금 당장 작동하는 쓰레기가 완벽한 기획서보다 낫다. 텔레그램으로 배포 중인데 코드가 지저분해서 고칠 엄두가 안 난다.

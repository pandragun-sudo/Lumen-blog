눈을 떴을 때 이미 83MB짜리 데이터베이스 덤프가 평문으로 깃허브에 올라가 있었다. 외부 개발자의 전화를 받고 식은땀이 흘렀다. 환경변수 파일마저 통째로 노출된 상태. 인간의 피로도가 만들어낸 가장 멍청하고 치명적인 실수다. git push를 타이핑하던 내 손가락을 저주했지만 이미 벌어진 일이다. 터미널을 열고 수동으로 커밋 내역을 뒤적거리는 짓은 두 번 다시 하고 싶지 않았다.

안티그라비티 2.0의 스킬 기능을 열고 당장 .agents/skills/auto_push/SKILL.md 파일을 갈겨 썼다. AI에게 기계적인 검열관 역할을 강제하는 수밖에 없다. API 키나 대용량 파일이 있는지 무조건 스캔하고, main 브랜치면 무조건 거부하도록 룰을 짰다. 이제 캔버스에 "정리해서 푸시해"라고만 친다. 인간의 개입이 빠질수록 시스템은 역설적으로 더 안전해진다.

데이터 수집도 마찬가지다. 매일 수천 개의 유튜브 쇼츠 데이터를 크롤링하고 엑셀로 노가다를 하는 건 미친 짓이다. morning_briefing 스킬을 만들었다. 아침마다 백엔드 DB를 긁어와서 급상승 키워드만 텔레그램으로 던져준다. 나는 그저 알림창에 뜬 텍스트를 읽기만 하면 된다. 인간이 기계의 부품처럼 일하는 시대는 끝났다. 피로에 찌든 인간보다 무감각한 코드가 백배는 더 신뢰할 만하다.

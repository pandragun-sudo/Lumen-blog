API 할당량이 비정상적으로 녹아내린다. 계정 하나를 여러 명이 돌려쓰는 꼴을 보니 속이 뒤틀렸다. 개발자 도구를 열어 API 엔드포인트를 털어가는 놈들도 있다. 500ms 간격으로 debugger를 무한루프 시켜 브라우저를 백지상태로 만들었다. F12를 누르는 순간 /api/user/devtools-report로 IP를 수집해 DB에 박제한다. 문을 따려는 시도조차 허용하지 않는다.

동시 접속 킥아웃 로직을 짰다. 구글 로그인 시 발급되는 UUID를 DB의 current_session_id와 비교한다. 다른 기기에서 접속하면 기존 세션은 즉시 파기된다. 누군가 새로고침을 하는 순간 401 에러를 맞고 길바닥으로 튕겨 나간다. 내 돈이 새어나가는 걸 방관하는 건 죄악이다. 

봇들이 매크로를 돌려 검색 쿼터를 증발시킨다. 서버 요금이 터지기 일보 직전이었다. daily_search_count를 추적하다가 50, 100, 500회 임계점을 넘으면 텔레그램 알림을 쏘게 했다. 비정상적인 패턴이 보이면 텔레그램 커맨드로 그 자리에서 Ban을 때리거나 티어를 강등시킨다. 철저하게 밟아버려야 기생충들이 꼬이지 않는다. 방어선을 높일수록 숨통이 트인다.
